# Project to test pi-durable with a nextjs frontend

## Frontend
- Nextjs app that chats with hono backend running pi-durable
- Shadcn components for UI
- Chat SDK https://chat-sdk.dev/

## Backend
- Hono app with pi-durable
- Typescript
- pi-durable (this is a new SDK get all the information from https://earendil.com/posts/pi-durable)
- pi-durable examples in https://github.com/earendil-works/pi/tree/main/packages/durable/test/examples
- pi-durable uses SQLITE for session storage
- Hono https://hono.dev for HTTP endpoint


## Code style
- Excelent human readable source code. Always trade readability over optimization.
